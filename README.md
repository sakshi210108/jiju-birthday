# 🎂 Happy Birthday JIJU - Galaxy Birthday Website 🌌

A beautiful interactive birthday website created using HTML, CSS, and JavaScript.

This project creates a cinematic birthday experience with a galaxy theme, animations, fireworks, music, and a surprise gift opening animation.

---

# ✨ Features

## 🌌 Galaxy Experience
- Animated galaxy background
- Twinkling stars
- Shooting stars
- Floating sparkles

## 🖥 Windows Boot Screen
- Startup animation
- Loading effect
- Birthday system initialization

## 💻 PyBirthdayWish Terminal
- Animated terminal typing effect
- Birthday system messages
- Futuristic interface

## 🎁 Gift Experience
- 3D animated gift box
- Gift opening animation
- Surprise reveal message

## 🎆 Celebration Effects
- Real HTML5 Canvas fireworks
- Floating balloons
- Falling confetti
- Floating hearts

## 🎵 Music System
- Background birthday music
- Play and pause controls
- Supports custom MP3 files

## 📸 Screenshot Feature
- Save your birthday moment as an image

## 📱 Responsive Design
- Works on:
  - Desktop
  - Laptop
  - Tablet
  - Mobile devices
